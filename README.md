## 🚀 About Me

I'm a **B.Sc. IT student from Mumbai, India** who enjoys building practical software and working close to the hardware.

My interests sit at the intersection of **web development, backend systems, automation, AI, networking, and computer hardware**. I like understanding systems end-to-end — from writing code and designing interfaces to deploying applications and troubleshooting the machines they run on.

- 🎓 Pursuing **B.Sc. Information Technology**
- 💻 Building **full-stack web applications** and backend services
- ☕ Learning **Java, DSA, and modern software development**
- 🧰 Hands-on with **PC building, laptop repair, hardware troubleshooting, and networking**
- 🤖 Exploring **AI/ML, automation, and intelligent systems**
- 👥 President of **DevClub** and involved in peer-to-peer technical learning
- 🌱 Interested in **open source, system design, and self-hosted infrastructure**
- 📍 Mumbai, India
